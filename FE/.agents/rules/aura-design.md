Create a workspace design rule based on:

@docs/AURA-DESIGN-DIRECTION.md

The rule must enforce:

- Preserve strong visual hierarchy.
- Prefer whitespace over additional UI components.
- Avoid excessive cards.
- One major visual idea per viewport.
- Avoid unnecessary gradients.
- Avoid excessive shadows.
- Avoid excessive rounded containers.
- Use animation only when it improves storytelling or interaction.
- Never add visual elements merely to make the page look "more premium".
- Images should function as compositions, not decoration.
- Typography must carry part of the visual identity.
- Maintain consistent spacing and grid alignment.
- Preserve accessibility and responsive behavior.
- Do not rewrite architecture unnecessarily.
- Before adding a new component, determine whether an existing component can serve the same purpose.
